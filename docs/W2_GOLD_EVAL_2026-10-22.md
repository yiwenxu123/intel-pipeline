## 5. 结论与下一步

1. 标注本身可用；当前评分存在**可解释的系统性偏差**：偏海外政策/通用医疗，低估中国地方政策与老龄健康研究。
2. 先完成 17 条 either 的二次确认，再冻结金标。
3. 然后做评分标准 v2：
   - 增加“中国/受众相关性”与“内容潜力”轴
   - 对海外政策/通用医疗研究设降分或硬门槛
   - 区分“新闻/政策/研究/讨论”内容类型
   - 门槛在 rubric 校准后再调，不先降 5.5
4. 规则预筛的知乎问题漏杀先记录，不基于单条样本立即改规则；W2-02 时一起评估是否允许“讨论/钩子”型信号。

## 7. 专业复核后的 v2 金标

### 0083 猫/癌症研究

原文只有 283 字：猫肿瘤基因组与人类肿瘤有相似性，可能帮助猫的精准治疗，并为人类癌症提供线索。  
没有老年人、衰老、中国场景或可执行信息，本质是**泛健康趣闻**，不是银发产业核心情报。

专业建议：标 `either`，保留为“泛健康/趣闻”候选，但不作为核心养老正例。  
如果标 `select`，会教模型把“任何癌症/宠物研究”当成养老相关内容，和拒绝癌症医院建设、通用医疗的逻辑冲突。

如果账号确实有“健康趣闻”栏目，应在 rubric 里单独设 `health_curiosity` 类型，给低权重/低配额，而不是混进核心 precision。

### 日本政策

- `0030` 障害福祉访问服务：有具体时间、现行减算规则、问题背景、新设方向，1254 字 → `select` 合理
- `0050` 居家介护管理者资格：有日期、现行要求、替代方案、政策目的，967 字 → `select` 合理
- `0047` 日间照护倒闭：有 47 件倒闭、162 万利用者、6 成送迎缺人等数据 → `select` 合理
- `0026` 家庭医生信息上线通知、`0041` 研讨会资料清单、`0054` 介护保险部会议事录：都是通知/目录/会议记录，没有可操作内容 → `reject` 合理

结论：日本政策不是按国家一刀切，而是看**实质内容 + 对中国/行业的借鉴价值**。rubric v2 应把“官方来源”与“内容实质”分开，官方来源不能自动加分。

### 0059 / 0081 知乎问题

- `0059` 是知乎热榜的医院义诊轶事（325 字），不是专业文章，也不是最新研究 → `reject`
- `0081` 是纯问题、无正文 → 按同一标准 `reject`

这也说明规则预筛拒绝 `0081` 是**正确**的，不需要为“裸问题/钩子”破例。若以后要保留讨论型内容，应要求来源本身有实质讨论，而不是一句提问。

## 8. v2 评分标准评测（Ark Plan deepseek-v4.1-flash）

数据：frozen v2 gold 100 条（94 条非 either）。  
评测方式：规则预筛 + v2 prompt + 质量闸门；5 条一批，逐批跑。

**建议 v2 采用 5.0 门槛**，兼顾准确率和召回；每日精选量会比 5.5 增加，但 Top20 不受影响。

### 说明

- 5 条批量拒答（网页导航、台风、蒙古火灾等）已单独重跑/确认；其中 4 条重跑后仍为负例，1 条是网页导航；整体指标不受影响。
- 评测仍是 **in-sample**：rubric 和门槛都基于这 100 条设计。上线前需要用新的 50–100 条 holdout 验证，不能把 87.1/81.8 当作最终线上指标。
- 主要漏报：老龄健康研究、日本介护政策、行业活动预告，分数集中在 4.0–5.4；5.0 门槛能救回一部分。
- 主要误报：日本政策通知、日本食品企业收购案例；v2 仍有少量海外内容偏宽。
- 生产仍使用旧 `scoring.md` + SenseNova `deepseek-v4-flash`；v2 与 Ark 模型均未上线。
